## Featured Projects

### AI & Machine Learning

**[AI-Powered Resume Screening System](https://github.com/chandimacbbandara/Resume-Screening-System)** &nbsp; [![Live Demo](https://img.shields.io/badge/Live_Demo-FF7C00?style=flat-square&logo=huggingface&logoColor=white)](https://huggingface.co/spaces/chandimabandara/Resume-Screening-System)

An intelligent, RAG-based recruitment tool that automates the candidate evaluation process. It extracts text from uploaded PDF resumes using `pdfplumber`, actively scrapes embedded portfolio links (GitHub, personal sites) via `BeautifulSoup`, and passes the enriched context through an instruct-tuned `Qwen 2.5 7B` model via the Hugging Face API. The model scores the candidate against job requirements, generating a structured gauge chart report — all through a Gradio web dashboard.

`Python` `LangChain` `FAISS` `Gradio` `pdfplumber` `RAG` `Qwen 2.5 7B` `Hugging Face`

---

**[Semantic Priority Analysis — LMS Support Triage](https://github.com/chandimacbbandara/Semantic-Priority-Analyser)** &nbsp; [![Live Demo](https://img.shields.io/badge/Live_Demo-FF7C00?style=flat-square&logo=huggingface&logoColor=white)](https://huggingface.co/spaces/chandimabandara/lms-priority-analyser)

An NLP-driven triage system that classifies and prioritises support tickets in Learning Management Systems using semantic understanding. Built on transformer-based sentence embeddings to capture meaning beyond keyword matching.

`Python` `Transformers` `NLP` `Scikit-learn` `Hugging Face`

---

**[Student Mental Health Early Detection System](https://github.com/chandimacbbandara/stress-level-prediction-ai)** &nbsp; [![Live Demo](https://img.shields.io/badge/Live_Demo-FF7C00?style=flat-square&logo=huggingface&logoColor=white)](https://huggingface.co/spaces/chandimabandara/stress-level-prediction-ai)

An end-to-end machine learning pipeline that predicts student stress and mental health risk levels from survey-based inputs. Trained, evaluated, and deployed live as an interactive web app on Hugging Face Spaces.

`Python` `Scikit-learn` `TensorFlow` `Gradio` `Hugging Face`
